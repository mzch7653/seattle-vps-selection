## 常见问题

**西雅图 VPS 国内延迟大概多少？**
第三方测评给 RackNerd 西雅图的口径是本地 Ping 约 160ms、三网去程直连；走 CN2 GIA 的节点能压到 140ms 以内。这三个数字都来自第三方测评转述，你自己的线路可能更好也可能更差，以实测为准。LisaHost 西雅图这条线官方明确说不做大陆直连优化，不适用这个参考值。

**西雅图和洛杉矶怎么选？**
两地都是美西，物理延迟差距不大，真正的差别在商家在哪个机房买了什么线路。洛杉矶的优化线路产品选择更多、货也更杂；西雅图的低价年付和住宅 IP 供给相对集中。选城市不如选线路——先看你需要的线路在哪家有货。

**住宅 IP VPS 和普通 VPS 差在哪？**
差在 IP 的性质。普通 VPS 拿到的是数据中心 IP，住宅 IP VDS 拿到的是当地宽带运营商分配给家庭宽带的地址。对平台风控判断来说，这是两回事；对 CPU、内存、带宽这些算力指标来说，住宅 IP 产品通常更贵而不是更强。搞清楚你的瓶颈是算力还是 IP。

**流量用超了会怎样？**
各家规则不同。SpartanHost 是限速 5Mb/s 继续跑、不停机；RackNerd 超流量要额外付费；LisaHost 的西雅图套餐标了具体流量额度，也有不限流量的版本可选，怕超就直接选不限量那档，比事后补流量省心。

**能装 Windows 吗？**
LisaHost 西雅图这批产品官方页面写了支持安装 Windows；SpartanHost 也支持 Linux、Windows 和自定义 ISO。RackNerd 官方列的是各类 Linux 发行版，需要别的系统可以提交工单申请自定义 ISO。

**需要备案吗？**
美国机房不需要备案，这也是很多人拿海外 VPS 做建站测试的原因之一。
